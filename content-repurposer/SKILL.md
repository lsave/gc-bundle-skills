# 社媒内容做同款

> 将长文章/视频自动拆解为适合不同平台的短内容

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：读取原始长文（read_file）

用 `web_fetch` 抓取页面内容 / 用 `read_file` 读取文件。

### 能力2：提取核心观点和金句

用 `web_fetch` 抓取原始内容页面，用 `read_file` 读取本地文件，按目标平台的格式要求重新组织内容。

### 能力3：改编为小红书图文/推文/短视频文案等多种格式

用 `web_fetch` 抓取原始内容页面，用 `read_file` 读取本地文件，按目标平台的格式要求重新组织内容。

### 能力4：适配各平台字数和排版规范

用 `web_fetch` 抓取原始内容页面，用 `read_file` 读取本地文件，按目标平台的格式要求重新组织内容。

### 能力5：输出多平台内容包

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 原始内容的链接或文件路径
- 原始内容类型（文章/视频/播客/PPT）
- 要转化为什么平台的内容？（小红书/抖音/微博/公众号/Twitter）
- 是否需要调整风格或调性？

### 步骤 2：运行脚本处理数据

```bash
python3 scripts/content_repurposer_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 3：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **多平台内容包（小红书+推文+视频文案）**

输出格式要求：多个文件，分平台格式输出

### 步骤 4：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
