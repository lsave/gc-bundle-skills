# 创建定时任务：每日星座行动建议

> 每日星座专属指引，规划当日行动

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：询问我的星座

用 `automation_update` 创建每日定时任务，每天自动执行 `web_search` 搜索最新运势信息。

### 能力2：每天早上

用 `automation_update` 创建每日定时任务，每天自动执行 `web_search` 搜索最新运势信息。

### 能力3：生成当日行动建议（适合做什么/不适合做什么）

用 `write_to_file` 生成文件。

### 能力4：用 automation_update 创建定时推送任务

用 `automation_update` 创建定时任务。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 你的星座是什么？
- 希望每天几点收到运势推送？
- 想要哪些维度的运势？（事业/爱情/财运/健康）

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[星座] 今日运势")
web_search("[星座] 每日运程 [日期]")
web_search("[星座] horoscope today")
```

确保获取到以下资源：
- 星座运势链接
- 每日行动建议

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/daily_horoscope_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **每日星座简报（Markdown）**

输出格式要求：文字简报 + 定时任务确认

### 步骤 5：设置定时任务

用 `automation_update` 创建定时任务：
```
automation_update:
  name="创建定时任务：每日星座行动建议"
  rrule=FREQ=DAILY;BYHOUR=9;BYMINUTE=0
  prompt="执行创建定时任务：每日星座行动建议skill的定时任务"
```

### 步骤 6：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议
4. 定时任务创建确认

**生成时间**: YYYY-MM-DD HH:MM

| 名称 | 链接 | 说明 |
|------|------|------|

[具体的下一步建议]

## 验收标准

- ✅ 定时任务创建成功
- ✅ 每日推送
- ✅ 运势内容个性化
- ✅ 行动建议具体可执行

## 场景化适配

根据不同星座和日期调整建议内容


## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
