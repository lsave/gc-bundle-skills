# 经济数据查询

> 读懂 GDP、利率、CPI，把握市场关键参考

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：联网搜索最新 GDP/CPI/利率/PMI 等数据（web_search）

用 `web_search` 搜索相关信息。

### 能力2：整理数据趋势和关键变化

用 `web_search` 搜索最新经济数据发布，用 `web_fetch` 抓取统计局/央行官网数据。

### 能力3：解读央行最新政策

用 `web_search` 搜索最新经济数据发布，用 `web_fetch` 抓取统计局/央行官网数据。

### 能力4：分析对投资/消费的影响

运行脚本进行数据分析处理。

### 能力5：生成宏观经济简报

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 关注哪个国家/地区的经济数据？
- 关注哪些指标？（GDP/CPI/PMI/利率/就业）
- 数据时间范围（最新/近1年/近5年）
- 输出形式（简报/详细报告/数据表格）

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[国家] GDP 最新数据 [年份]")
web_search("[国家] CPI inflation rate latest")
web_search("[国家] 经济数据 宏观经济指标")
```

确保获取到以下资源：
- 经济数据源链接
- 政策原文链接

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/macro_economy_brief_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **宏观经济简报（Markdown）**

输出格式要求：Markdown 经济简报 + 数据表格

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
