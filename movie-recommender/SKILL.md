# 影视推荐小助手

> 周末不知道看啥？按口味精准推荐，片源直接给到

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：询问我的口味偏好（类型/心情/场景）

用 `web_search` 搜索豆瓣/IMDb高分影片列表，用 `web_fetch` 抓取影片详情页获取评分、剧情简介、演员信息。

### 能力2：联网搜索高分影视（web_search）

用 `web_search` 搜索相关信息。

### 能力3：推荐

用 `web_search` 搜索豆瓣/IMDb高分影片列表，用 `web_fetch` 抓取影片详情页获取评分、剧情简介、演员信息。

### 能力4：提供观看渠道链接

用 `web_fetch` 抓取页面内容 / 用 `read_file` 读取文件。

### 能力5：生成推荐清单文档

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 想看什么类型的影视？（动作/爱情/科幻/悬疑/纪录片/动漫）
- 最近看过什么比较喜欢的？
- 观影场景（独自/约会/家庭）
- 对地区有偏好吗？（国产/日韩/欧美/港台）

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[类型] 电影推荐 高分 2024")
web_search("类似[参考影片] 电影推荐")
web_search("[类型] movie recommendation imdb top")
```

对搜索结果中的重要链接，用 `web_fetch` 抓取页面详细内容，提取关键信息。

确保获取到以下资源：
- 豆瓣/IMDB 评分数据
- 流媒体观看链接

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/movie_recommender_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **推荐清单文档（含评分+链接）**

输出格式要求：推荐清单 + 评分 + 观看链接

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
