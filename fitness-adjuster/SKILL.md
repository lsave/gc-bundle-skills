# 锻炼任务调整

> 锻炼计划乱了？帮你重新安排锻炼节奏

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：读取当前运动计划文件（read_file）

用 `web_fetch` 抓取页面内容 / 用 `read_file` 读取文件。

### 能力2：询问调整原因（受伤/时间变化/目标变化）

用 `read_file` 读取现有训练计划，根据用户反馈调整动作和强度，用 `write_to_file` 生成调整后的计划。

### 能力3：生成替代方案

用 `write_to_file` 生成文件。

### 能力4：更新运动计划文件（write_to_file）

用 `read_file` 读取现有训练计划，根据用户反馈调整动作和强度，用 `write_to_file` 生成调整后的计划。

### 能力5：调整定时提醒

用 `automation_update` 创建定时任务。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 你的健身目标是什么？
- 今天身体状态如何？（精力充沛/一般/疲惫/有不适）
- 当前训练计划文件路径（如有）
- 需要调整什么？（强度/动作/时间）

### 步骤 2：运行脚本处理数据

```bash
python3 scripts/fitness_adjuster_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 3：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **更新后的运动计划文件**

输出格式要求：更新后的运动计划文件 + 调整说明

### 步骤 4：设置定时任务

用 `automation_update` 创建定时任务：
```
automation_update:
  name="锻炼任务调整"
  rrule=FREQ=DAILY;BYHOUR=9;BYMINUTE=0
  prompt="执行锻炼任务调整skill的定时任务"
```

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议
4. 定时任务创建确认

## 验收标准

- ✅ 读取了原计划
- ✅ 替代方案合理
- ✅ 计划文件已更新
- ✅ 定时任务已调整

## 场景化适配

根据调整原因（伤病/时间/器材）提供不同方案


## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
