# 自律习惯管理

> 好习惯总坚持不了？21天打卡+数据追踪帮你养成好习惯

## 前置依赖

```bash
pip install pandas openpyxl
```

## 核心能力

### 能力1：创建习惯打卡列表（早起/阅读/运动等）

用 `web_search` 搜索习惯养成的科学方法，用 `automation_update` 创建每日打卡提醒定时任务。

### 能力2：设置每日打卡提醒（automation_update）

用 `automation_update` 创建定时任务。

### 能力3：记录每日完成情况（write_to_file）

用 `web_search` 搜索习惯养成的科学方法，用 `automation_update` 创建每日打卡提醒定时任务。

### 能力4：统计连续天数和完成率

用 `web_search` 搜索习惯养成的科学方法，用 `automation_update` 创建每日打卡提醒定时任务。

### 能力5：生成

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 想养成什么习惯？（早起/读书/运动/冥想/写日记）
- 每天计划投入多长时间？
- 是否有过尝试？失败原因是什么？
- 希望从哪天开始？

### 步骤 2：运行脚本处理数据

```bash
python3 scripts/habit_builder_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 3：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **打卡记录表**
- **习惯报告**

输出格式要求：打卡记录 + 统计数据 + 习惯报告

### 步骤 4：设置定时任务

用 `automation_update` 创建定时任务：
```
automation_update:
  name="自律习惯管理"
  rrule=FREQ=DAILY;BYHOUR=9;BYMINUTE=0
  prompt="执行自律习惯管理skill的定时任务"
```

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议
4. 定时任务创建确认

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
