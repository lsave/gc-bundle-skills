# 自媒体内容一键生成

> 日更不知道写啥？定领域平台，全自动从选题到成文直接喂到发布

## 前置依赖

```bash
pip install pandas
```

## 核心能力

### 能力1：询问我的领域和目标平台

用 `web_search` 搜索该主题的热门内容和爆款案例，分析标题、结构和互动数据。

### 能力2：检索当前热点话题（web_search）

用 `web_search` 搜索相关信息。

### 能力3：生成选题分析报告

用 `write_to_file` 生成文件。

### 能力4：撰写完整文章/帖子（适配目标平台格式）

用 `web_search` 搜索该主题的热门内容和爆款案例，分析标题、结构和互动数据。

### 能力5：生成封面标题建议和发布时间建议

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 要创作什么类型的内容？（公众号/小红书/抖音/知乎/Twitter）
- 内容主题是什么？
- 目标受众是谁？
- 希望的风格/调性（专业/轻松/搞笑/治愈）
- 字数要求

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[主题] 热门文章 爆款")
web_search("[主题] [平台] 爆款标题公式")
web_search("[主题] trending content ideas")
```

确保获取到以下资源：
- 热点话题分析
- 竞品内容参考链接

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/content_creator_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **完整文章/帖子**
- **封面标题建议**
- **发布排期**

输出格式要求：Markdown 文章 + 选题分析 + 发布建议

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
